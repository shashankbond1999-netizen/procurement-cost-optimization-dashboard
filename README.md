## Project Overview

This project analyzes procurement spending, supplier performance, material costs, and delivery efficiency using Python and Power BI.

## Tools Used

- Python
- Pandas
- Power BI
- Excel
- GitHub

## Key KPIs

- Total Spend
- Average Unit Price
- Total Quantity
- Average Delivery Delay

## Key Insights

- Vendor A accounted for the highest procurement spend.
- Steel was the highest-spend material category.
- Supplier spending was concentrated among a few vendors.
- Delivery delays varied across suppliers.
- Procurement data revealed opportunities for cost optimization.

## Business Recommendations

- Negotiate pricing with high-spend suppliers.
- Monitor supplier delivery performance regularly.
- Diversify procurement sources to reduce dependency risk.
