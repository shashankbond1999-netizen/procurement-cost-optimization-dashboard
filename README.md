# Procurement Cost Optimization Dashboard

## 📖 Problem Statement
Analyze procurement data to identify cost inefficiencies, vendor performance issues, and opportunities for cost optimization.

## 🛠 Tools Used
- SQL
- Python (Pandas, NumPy)
- Power BI
- Excel

## 📊 Key KPIs
- Total Procurement Cost
- Average Cost per Unit
- Delivery Delay %
- Vendor Performance Score

## 📈 Key Insights
- Identified high-cost vendors contributing to excess spend
- Delivery delays increased procurement costs
- Recommended cost-efficient vendors

## 🧠 Business Impact
This project helps businesses:
- Reduce procurement costs
- Improve vendor selection
- Optimize operations

## 📂 Project Structure
- data/ → dataset
- sql/ → SQL queries
- python/ → analysis
- dashboard/ → Power BI file
- images/ → dashboard screenshots
